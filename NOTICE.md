# Aviso

**MR- Nosotras, las brujas** es una ayuda de mesa no oficial para Foundry VTT. No incluye el reglamento: **hace falta el manual del juego** (Primigenia Austral, https://primigenia-austral.itch.io/nosotras-las-brujas).

*Nosotras, las brujas* es un juego de Hernán D'Andreis (Aleph Perth) y Keith Monardes, publicado por Primigenia Austral, con ilustraciones de Ferenike. El nombre del juego, las tablas de conceptos, arquetipos y preguntas de vínculo, y las reglas que este sistema automatiza son de sus autores.

- **Código** (carpetas `module`, `scripts`, `templates`, `styles`, `tests`): MIT, ver `LICENSE`.
- **Arte** (cartas, portada, retratos): original de este sistema, generado por código en `scripts/`; MIT.
- **Tipografías** IM Fell y Caveat: SIL Open Font License 1.1, ver `fonts/OFL.txt`.
- Este paquete no tiene relación con la editorial ni con los autores. Si lo piden, se retira.
